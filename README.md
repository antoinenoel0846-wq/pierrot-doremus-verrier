# Pierrot Dorémus — Verrier d'art, Gramat (46)

Proposition de page d'accueil pour l'atelier de verre soufflé de Pierrot Dorémus.

**Aperçu en ligne** : https://antoinenoel0846-wq.github.io/pierrot-doremus-verrier/

## À propos de cette maquette

Il s'agit d'une **maquette de présentation**, pas d'un site en service. Elle reprend
les contenus et les photographies de l'atelier à des fins de proposition commerciale.

- Les photographies appartiennent à Pierrot Dorémus.
- La page est en `noindex` : elle n'apparaîtra pas dans les moteurs de recherche et
  ne concurrence donc pas le site existant de l'atelier.
- Les horaires d'ouverture restent à compléter.

## Technique

Page statique autonome : un seul fichier HTML, aucune dépendance, aucun script tiers.
Typographie Fraunces et Poppins via Google Fonts.

Réalisation : [Antoine Noël](https://github.com/antoinenoel0846-wq)
